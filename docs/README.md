## 🚀 项目特色

- ✅ **现代设计系统** - 基于uiverse.io设计理念
- ✅ **专业图标库** - 集成iconoir.com (1671+免费图标)
- ✅ **多语言支持** - 简体中文、繁体中文、英文
- ✅ **玻璃拟态UI** - 现代化的视觉效果
- ✅ **TypeScript** - 完整类型定义
- ✅ **多端兼容** - H5、小程序、App一码多端

## 📋 文档贡献

如果您想为文档做出贡献，请遵循以下规范：

1. **文件命名**: 使用kebab-case命名，如 `design-system.md`
2. **目录结构**: 保持层级清晰，相关文档放在同一目录下
3. **内容格式**: 使用Markdown格式，遵循统一的格式规范
4. **图片资源**: 放在相应的 `assets/` 子目录下
5. **链接引用**: 使用相对路径，确保链接有效
